# VaultTracker 0.10.4

- Текст Telegram → Minecraft явно белый, включая сообщения с оформлением Flexity: цвет [TG] больше не наследуется текстом.
- Для непривязанного пользователя выводится имя и фамилия Telegram без дополнительного @username. Администраторские списки сохраняют полный профиль.
- messages.showTelegramTagLinked и messages.showTelegramTagUnlinked отдельно управляют [TG] для привязанных и непривязанных. true — показать, false — скрыть; по умолчанию оба true.
- Старый стандартный шаблон распознаётся автоматически; в новых шаблонах используйте {tg}, {sender}, {text}. После изменения конфигурации выполните /vtrack reload.

Для установки JAR требуется перезапуск сервера.
