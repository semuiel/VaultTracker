# VaultTracker 0.13.1 preview

- Коды FunPay принимаются в личном чате без предварительного открытия меню и без 10-минутного срока ввода. Нужна привязка игрового аккаунта; скрытие кнопки пожертвований не мешает погасить уже купленный код.
- Премиум: баланс, текущий статус LuckPerms, оставшееся время; 600 монет / 30 дней или 1000 / 60 дней. Продление добавляется к оставшемуся сроку. Бессрочная группа не превращается во временную.
- Суперадминистратор: выдача на 30/60 дней, снятие группы premium, начисление/списание баланса, журнал исполнителей и действий. Выбор игрока — по 20 строк, онлайн/офлайн и поиск.
- Списание и продление сохраняются одной транзакцией. Выдача LuckPerms через API и постоянную очередь; повторение после сбоя не списывает средства второй раз. Требуются LuckPerms и существующая группа premium.
- Общий локальный API баланса для будущего плагина сайта, отдельный ключ с ограниченным доступом. Документация: donations/BALANCE-API.md.
- Исправления FunPay: сохранение всех cookies приватной сессии, проверка оплаченного заказа без статусной метки, адресация чата по участникам заказа, отправка без устаревшего HTML-парсера ответа.

## Установка

Подготовлены отдельные JAR для Folia 26.1.2 и Paper/Folia 1.21.11. Выберите один, не ставьте оба. Новый Java-плагин требует штатного перезапуска выбранного сервера. Основной сервер автоматически не обновлялся.

Обновить также платёжный сервис: после остановки START.cmd сохранить копию папки, заменить service.py, ledger.py, funpay_provider.py из нового архива и запустить START.cmd. Конфигурация с ключами, donations.sqlite и его WAL/SHM сохраняются; таблицы расширяются автоматически. Не запускайте две копии сервиса над одной базой.

Полная переносимая сборка содержит Python и библиотеки. Старый config.local.json переносится самостоятельно, ключи и пользовательская база в архив не включены. Для интеграции сайта добавить website_api_key в закрытый конфиг по инструкции BALANCE-API.md.

Автоматические проверки не заменяют тест покупки и выдачи группы на вашем LuckPerms. Возврат FunPay отменяет баланс/бонус, но не отзывает уже выданный премиум автоматически; журнал и уведомление позволяют суперадминистратору снять его.
