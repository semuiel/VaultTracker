# VaultTracker 0.10.3

Привязанные пользователи Telegram пишут в игру под игровым ником с отметкой [TG]. Используются форматтер глобального чата Flexity, его цвет ника и сохранённый пользовательский префикс. Префикс добавляется перед отформатированной строкой Flexity. Работает для онлайн- и офлайн-персонажей; данные офлайн-оформления читаются из базы через пул самого Flexity без изменений базы.

Непривязанные пользователи сохраняют прежнее отображение Telegram-имени. Если Flexity отсутствует или его интерфейс изменился, сообщение отображается как [TG] Ник: текст. Интеграция проверена по приложенному flexity-1.0-SNAPSHOT.jar; другая версия Flexity может потребовать обновления адаптера.

В telegramchat.yml → messages можно добавить:

```yaml
  linkedPlayerIdentity: true
```

Параметр по умолчанию включён, поэтому существующий конфиг менять не обязательно. false возвращает прежний формат formats.telegramChat для всех пользователей. После изменения конфигурации: /vtrack reload.

Новое оформление — только отображение: не вызывает событие игрового чата, не исполняет команды персонажа, не создаёт обратного эха в Telegram. Текст Telegram вставляется как обычный текст. Требуется полный перезапуск для установки JAR.
