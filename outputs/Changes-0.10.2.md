# VaultTracker 0.10.2

- Регистрация хранилищ без лимита, в том числе при старом значении 100 в config.yml.
- «Мои ресурсы» → «Найти ресурс в сундуках»: поиск по названию на русском или английском, включая часть слова.
- `/find diamond_ore [страница]`: тот же поиск в игре, только свои зарегистрированные сундуки. Кнопки страниц кликабельны. При конфликте команды с другим плагином используйте `/vaulttracker:find`.
- По 20 результатов на страницу: ресурс, количество, мир, координаты и расстояние. Ближайшие в текущем мире сначала; другие миры следом. Для офлайн-игрока расстояние недоступно, применяется сортировка по миру и координатам.
- Двойной сундук отображается один раз, с координатами ближайшей половины. Остатки берутся из каталога; незарегистрированные сундуки не сканируются.
- Фильтр U+E000 для глобального чата Flexity сохранён в шаблоне.
- Накопление чата настраивается: messages.mergeWindowSeconds: 0 — сразу, 5 — за пять секунд. Достижения накоплением не задерживаются.

Установка: замените прежний JAR и перезапустите сервер. Базы и привязки сохраняются. /list остаётся списком онлайн-игроков с 20 игроками на странице и удалением ответа через 300 секунд.
