# Чат-мост VaultTracker 0.10.0

Установите `VaultTracker-0.10.0.jar` вместо прежнего JAR и перезапустите сервер. Новый файл `plugins/VaultTracker/telegramchat.yml` создаётся автоматически, модуль изначально выключен. Старые конфиги и базы сохраняются.

## Минимальная настройка

В `telegramchat.yml` заполните:

```yaml
enabled: true
token: "ТОКЕН_ЧАТ_БОТА"
chat:
  chatId: -1000000000000
  topicId: 486
  minecraftToTelegram: true
  telegramToMinecraft: true
advancements:
  enabled: true
  chatId: -1000000000000
  topicId: 123
```

Это пример: замените ID группы и темы на свои. `chat` — тема сообщений сервера; `advancements` — тема достижений, например флуд. Можно использовать и разные группы. `topicId: 0` — обычная группа/основная тема. Затем выполните `/vtrack reload`.

Прокси используются из `telegram-proxies.txt`, а при пустом списке — из `advanced.proxy` файла `telegram.yml`. Адрес Bot API, таймаут опроса и интервалы восстановления настраиваются отдельно в `advanced` файла `telegramchat.yml`. При общем токене единственный опрос выполняется с параметрами каталога. Токен чата независим от токена каталога; переменная окружения `VAULT_TELEGRAM_CHAT_TOKEN` имеет приоритет над файлом.

Если токены чата и каталога совпадают, VaultTracker получает обновления один раз и распределяет их между модулями. Два плагина с одним токеном, например tgbridge и VaultTracker, одновременно запускать нельзя: при переходе отключите tgbridge для этого токена. Если каталожный бот выключен, чат-бот работает самостоятельно. Ошибки чат-конфига не выключают каталог и игровой учёт.

## Поведение

- Minecraft → Telegram: по умолчанию нужен префикс `` (U+E000), как в приложенной конфигурации. В Telegram он убирается. Для всех сообщений поставьте `messages.requirePrefixInMinecraft: ""`. Используются отображаемые имена; это переключается через `useRealUsername`. Сообщения объединяются за 5 секунд; `mergeWindowSeconds: 0` отключает объединение.
- Telegram → Minecraft: текст и обозначения медиа с подписями пересылаются только из указанной темы. Содержимое файлов не скачивается. Для получения обычных сообщений отключите Privacy Mode в @BotFather либо выдайте боту права администратора группы. Входящие команды не исполняются в Minecraft. Сообщения других ботов пропускаются.
- Достижения: независимая тема; отдельно включаются task, goal и challenge, описания и звук. Рецепты и достижения без публичного отображения пропускаются. Ванильные названия переводятся на русский из уже встроенного словаря. Для собственных переводов можно создать `telegramchat-lang.json`: например `{"my.advancement.title":"Название"}`.
- `/list` и `/list@имя_бота`: только в теме чата сервера, по одному игроку на строку, до 20 игроков в сообщении. Для следующих 20 отправляется следующее сообщение. Значки определяются по типу мира: Верхний мир, Незер, Энд, другое измерение. Список обновляется при входе, выходе и переходе между измерениями.
- Входы, выходы, смерти, запуск и остановка сервера выключены по умолчанию, как в приложенном tgbridge. При необходимости включите их в `events`. Сообщение об остановке отправляется с ограниченным временем ожидания и не гарантируется при обрыве связи.

Мост использует стандартное событие Paper `AsyncChatEvent` и уважает его отмену. Специальные интеграции tgbridge с отдельными чат-плагинами, Discord, картами, голосовым чатом, vanish и служебными событиями Telegram в эту версию не перенесены.

## Оформление и эмодзи

Все подписи и шаблоны находятся в `formats`, значения переменных описаны комментариями. Telegram использует HTML, Minecraft — MiniMessage. Пользовательский текст вставляется безопасно, без выполнения тегов или команд.

Для каждого измерения можно задать обычный `emoji` и необязательный `customEmojiId`:

```yaml
list:
  dimensions:
    nether:
      emoji: "🔥"
      customEmojiId: "ЧИСЛОВОЙ_CUSTOM_EMOJI_ID"
```

Вместо текстовой заглушки нужен настоящий числовой `custom_emoji_id`, в кавычках. Это ID кастомного эмодзи, не ID набора и не `file_id`. Он присутствует в `entities[].custom_emoji_id` сообщения Telegram с этим эмодзи. Пустая строка оставляет обычный смайлик.

В шаблонах Telegram также допустим `<tg-emoji emoji-id="123456789">🙂</tg-emoji>`. ID здесь — пример. Согласно [Telegram Bot API](https://core.telegram.org/bots/api#html-style), для использования кастомных эмодзи требуется Premium у владельца бота либо дополнительное имя, приобретённое через Fragment. Обычный emoji нужен как запасной вариант. При явном отклонении кастомного эмодзи Telegram бот повторит отправку с обычным смайликом.

## Сбои и проверка

Отправка и опрос выполняются в фоне. Сбой Telegram или прокси не блокирует игровые события. Очередь чата хранит не более 1000 сообщений до 10 минут; при заполнении новые сообщения пропускаются, при перезапуске очередь очищается. После неопределённого сетевого сбоя повторная доставка может дать дубликат. Явные ошибки прав, темы или HTML пропускаются с записью причины в консоль. Очередь охраны каталога сохраняет свои прежние правила.

Автоматические тесты проверяют темы, направления, `/list`, измерения, русские достижения, общий токен, наследование прокси и замену кастомных эмодзи при отказе Telegram. Работа с вашими настоящими ботами и установленным серверным чат-плагином требует проверки на сервере после заполнения настроек.

Исходная конфигурация изучалась по вашему tgbridge и [документации проекта](https://github.com/vanutp/tgbridge); реализация моста находится внутри VaultTracker.
