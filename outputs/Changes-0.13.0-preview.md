# 0.13.0-preview: пожертвования (не установлено на сервер)

Добавлены меню пожертвований для связанных аккаунтов и управление видимостью у супер администратора. Баланс хранится в отдельном сервисе SQLite; премиум пока является заглушкой.

Оплаченный заказ проверяется повторно при вводе одноразового кода. Подтверждение получения на FunPay запрашивается после зачисления. За любой честный отзыв на закрытый заказ начисляется 10% один раз; возврат отменяет основное начисление и бонус. Отрицательный баланс после возврата помечается для блокировки будущих покупок; супер администраторам создаётся уведомление.

Создан и сохранён **неактивный** лот: https://funpay.com/lots/offerEdit?node=1753&offer=77604794 . Ссылка покупателя для будущей настройки: https://funpay.com/lots/offer?id=77604794 . Цена одной единицы лота — 1 ₽, за неё выдаётся одна монета. Комиссия FunPay/платёжного метода увеличивает цену для покупателя.

JAR для 1.21.11 требует Java 21; JAR для Folia 26.1.2/26.2 — Java 25. Устанавливать только соответствующий вариант при плановой остановке. Основной сервер не изменялся.

Сервис FunPay не подключён: нужны локальная авторизация продавца, отдельный процесс в том же сетевом окружении, что Minecraft, и контрольный заказ для проверки актуальной разметки сайта. Если Crafty запускает Minecraft в контейнере, 127.0.0.1 относится к этому контейнеру; перед запуском нужно определить размещение сервиса. Не открывать платёжный порт наружу. Публичные продажи до проверки не включать.

См. donations/README.md в исходниках или архиве сервиса. Ни golden_key, ни api_key не входят в сборку; все функции по умолчанию отключены.
