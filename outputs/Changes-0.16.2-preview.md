# VaultTracker 0.16.2-preview

Передача проекта: исходный код, тесты, Gradle wrapper, примеры конфигурации и готовый JAR для Folia 26 / Java 25.

Изменения после 0.13.4:
- Полноценное торговое меню Telegram и личный кабинет с данными игрока, здоровьем, голодом, координатами, временем игры и премиумом.
- Меню администратора и суперадминистратора с переключаемыми правами. Flexity vanish скрыт из публичного /list.
- В уведомлениях об изменении сундука администратор видит ник участника; обычный игрок — без ника. Кнопки личного сообщения от FLEXITY, бана на пять минут, заморозки через Flexity и игнорирования.
- Поиск собственных ресурсов направляет компас к ближайшему сундуку; выбор конкретного сундука доступен нажатием координат в игре или кнопкой предмета с количеством в Telegram.
- Тексты меню настраиваются в telegram-menu.yml, эмодзи предметов — в item-emojis.yml. Эти файлы создаются в папке плагина при первом запуске.
- Сервис пожертвований и премиума в donations; реальные ключи и базы в репозиторий не включены.

Проверка: Gradle test shadowJar, 243 теста успешно. Серверные данные не входят в сборку проекта.
