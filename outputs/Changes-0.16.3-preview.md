# VaultTracker 0.16.3-preview

Привязка игрового персонажа к Telegram запускает от консоли `/bastion trust add <ник>`. Выдача доверия сохраняется как ожидающая и повторяется при следующем входе, если Bastion или игрок временно недоступны. Состояние проверяется по собственному списку доверенных Bastion.

В карточке игрока доступны добавление в доверенные Bastion и удаление из списка. Суперадминистратору — сразу; обычным администраторам право «Доверие Bastion» включается отдельно. Перед выполнением запрашивается подтверждение, а права перепроверяются.

Bastion 1.0-SNAPSHOT принимает команды доверия только для игроков онлайн. Реальные серверные файлы, базы и токены не входят в репозиторий или JAR.
