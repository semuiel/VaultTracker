# Каталог действий бота

Сгенерировано из регистраций текущих исходников. Это стабильные идентификаторы, а не тексты пользовательского ввода. HANDLER означает проверку прав внутри существующего обработчика. Открытие/нажатие не доказывает успешное выполнение операции. Полный runtime-каталог с категориями доступен только Root через GET api/options.
