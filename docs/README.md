## Документы выпуска

[Отчёт разработки 0.17.77](report-0.17.77.md), [инструкция установки 0.17.77](release-0.17.77.md) и [отчёт Premium/Free](premium-free-coins-release.md) фиксируют условия и проверки **на момент соответствующей разработки**. Фразы «live не изменялся» относятся к тому этапу. Фактическая последующая установка 18.10.2026 описана в [handoff.md](handoff.md); это не указание повторно устанавливать релиз. Во время подготовки Git-передачи 19.10.2026 production не изменялся.

Рабочие конфиги, базы, runtime, серверные backups, результаты расследований и личные данные игроков в публичный репозиторий не включаются. Их передача — отдельная задача владельца; состав необходимого приватного комплекта указан в handoff.
