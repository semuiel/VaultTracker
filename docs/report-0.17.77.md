# Отчёт: VaultTracker 0.17.77

Изменения выполнены только локально. Основной сервер с игроками, SSH, рабочие базы, платёжный процесс и HTTPS-маршруты не проверялись и не изменялись. Qwen не использовался.

1. **Версия:** 0.17.77-preview-folia26. Предыдущие меню, права и функции сохранены; JAR предназначен для самостоятельной установки.
2. **Причина переплаты:** интервал существовал только в отображении. Новая временная метка создавала другой event ID, а resolve не проверял, что этот UUID уже получил награду площадки.
3. **Защита:** один канонический UUID/provider, атомарная проверка cooldown вместе с кошельком и ledger в SQLite BEGIN IMMEDIATE. Повторные события и гонки не дают вторую выплату.
4. **Период:** скользящие 24 часа после начисления. Более длинные интервалы сохраняются. Старые 0/короткие значения не отключают суточную защиту. Полночь не сбрасывает её.
5. **Где таймер:** vote_eligibility в существующей платёжной базе. После обновления он восстанавливается из последнего старого credited, без удаления или исправления истории.
6. **Reconcile/retry:** используются те же accept/resolve и прежняя outbox. Другой replay key внутри cooldown станет техническим событием, а не деньгами. Потеря ответа после commit не повторяет начисление; сбой до commit откатывает операцию целиком.
7. **Рейтинг:** новые технические повторы cooldown не считаются. Исторические credited сохранены: возможные прежние переплаты требуют отдельной сверки, не автоматического удаления.
8. **ТОП-3:** 300/200/100 на новой установке, независимые суммы. Существующий первый приз сохраняется. Ранги 1,1,3 и 1,2,2; full — каждому сумма ранга, split — разделить её с точным остатком по UUID. Старые закрытые месяцы не доплачиваются.
9. **Настройка:** Root → Экономика → Голосования и награды → Призы ТОП-3. Три кнопки, ввод и подтверждение; режим ничьей остаётся. Права проверяются обработчиками.
10. **Меню игрока:** «Голосования», награда каждой площадки, доступность/оставшееся время, актуальные три месячных приза и кнопка «Обновить». При старом пользовательском шаблоне достаточно поменять его заголовок, не весь конфиг.
11. **Откуда время:** persisted nextEligibleAt минус время backend, тот же источник проверяет выплату. Неизвестный/null/ошибочный статус не превращается в «Доступно».
12. **Игроки CoreProtect:** co_user плюс доступная история co_username_log, включая офлайн и прежние ники; существующий SELECT-only источник. 30 строк за запрос, ограниченная пагинация, таймаут и прежний двойной ACL.
13. **Ввод:** список при фокусе, поиск по части ника/UUID без учёта регистра, клавиатура, мобильный скролл и «ещё». Можно вписать ник/UUID вручную, в том числе если список недоступен. Материалы по-русски, галочки и copy-only rollback сохранены; команды через HTTP не исполняются.
14. **Инструментирование:** контекст Telegram update и централизованный реестр callback-маршрутов плюс явные hooks реальных результатов. Для отложенной привязки используется worker GuardService. Исходящие сообщения и Minecraft bridge не являются пользовательскими действиями.
15. **Охват:** кабинет, торговый поиск, ресурсы/история, друзья/доступ, сообщения, настройки/статистика, поддержка, премиум/пожертвования/Free-монеты/голосования, admin/Root и CoreProtect Mini App. Каталог регистраций приложен. Бизнес-успехи подключены для операций с достоверным результатом; успех произвольной игровой/консольной команды не угадывается из строкового ответа.
16. **Поиск:** player и item отдельно; открытие, фильтр, выполненный запрос и страницы различаются. Есть уникальные пользователи режимов, результаты/пустые ответы, язык, способ ввода, повторы распознанных запросов и время обработки. Популярные предметы/публичные ники показаны агрегированно, без истории конкретного человека.
17. **Отчёты:** семь вкладок, DAU/WAU/MAU, новые/вернувшиеся, сессии, D1/D7/D30, полные когорты, периоды до нескольких лет, сравнение периодов, месяцы/лучший месяц, heatmap, функции/поиск/ошибки и воронки link/premium/support. Воронка связывает завершение с последним начатым сценарием этой функции; это не финансовый аудит транзакций.
18. **Хранение:** bot-analytics.mv.db — отдельная H2 с постоянным HMAC, минимальным журналом и индексированными hourly/daily/session/flow агрегатами. Автоматического удаления нет. Очередь ограничена; при аварийном завершении может потеряться ещё не записанный хвост. Пропуски/ошибки и недоступность Telegram отмечаются; сохранение файла и backup обязательны.
19. **Доступ/приватность:** только Root, одновременно Telegram admin/creator указанного чата, проверенные initData и отдельная короткая сессия. Admin/SuperAdmin не получают новый доступ. Тексты, коды, ключи, initData/session tokens и содержание консоли в аналитику не сохраняются. Все API просмотра — GET-only.
20. **Будущая установка:** новый Python ZIP сначала, затем JAR при вашем штатном рестарте; новые botAnalytics settings и отдельный HTTPS path на прежнем listener. Никакие live-конфиги не менялись. Пошагово — release-0.17.77.md.
21. **Проверки:** Java: 490 passed, 0 failures, 0 errors, 1 прежний optional skip (всего 491). Python: 79/79. Браузер: CoreProtect, Telegram-статистика и Аналитика бота — пройдены. Проверены мобильный/desktop вид, ACL/revocation, XSS, фильтры/диапазоны, миграции и 1000 событий многолетнего стенда. Сборка test + shadowJar успешна, JDK 25, offline Gradle.
22. **Артефакты:** VaultTracker-0.17.77-preview-folia26.jar, payment-service-0.17.77.zip, SHA256SUMS.txt и этот отчёт в локальном outputs. Контрольные суммы сверены с протестированной сборкой.

## Пределы реализации

Нет произвольного восстановления прошлой истории Telegram и автоматической коррекции прежних переплат. Не все игровые административные операции имеют типизированный persisted outcome: для них доступны нажатия/экраны/отказы, но не неподтверждённый счётчик успешных наказаний. Аварийный обрыв процесса может потерять хвост analytics queue; финансовый ledger и существующие очереди голосов от неё независимы. Retention при пропусках сбора может быть занижен. Никаких live-проверок площадок, реального начисления, браузера бота в Telegram или подключения к рабочей MariaDB не проводилось.
