# VaultTracker 0.17.77-preview

VaultTracker для Minecraft Folia и Telegram-бота FLEXITY. Каталог отмеченных хранилищ, поиск ресурсов, личные сообщения, инструменты администрации, обращения игроков, пожертвования, Premium, награды за голосования и три Telegram Mini App.

**Текущая версия исходников: 0.17.77-preview-folia26.** Основной вариант — Folia 26.1.2 / Java 25. Совместимость с 26.2 проверялась ранее; точная compile API и зависимости зафиксированы в [build.gradle.kts](build.gradle.kts). Ветка `main` содержит передаваемую полную версию, включая Python-сервис и все frontend-исходники.

## Что входит в репозиторий

| Путь | Содержимое |

| `src/smoke/` | Отдельный тестовый плагин; никогда не устанавливать на основной сервер |
| `sql/` | SQL-пример поиска; инициализацию действующих схем выполняет код |
| `tools/` | Упаковка платёжного сервиса и запуск web-проверок |

В Git нет рабочих токенов, паролей, SQLite/H2-баз, Python runtime, локального Gradle cache и старых собранных архивов. Их передают администратору отдельно по защищённому каналу; список — в [handoff.md](docs/handoff.md). Старые версии остаются в истории Git, актуальные сборки создаются из исходников.

## Сборка и проверка

Нужен JDK 25. Первый запуск Gradle скачивает зависимости из Maven Central/PaperMC.

Windows PowerShell, из корня:

```powershell
.\gradlew.bat test shadowJar
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r donations/requirements.txt
.\.venv\Scripts\python.exe -m unittest discover -s donations -p "test_*.py"
.\.venv\Scripts\python.exe tools/package-payment.py
```

Linux, из корня:

```sh
sh gradlew test shadowJar
python3 -m venv .venv
.venv/bin/python -m pip install -r donations/requirements.txt
.venv/bin/python -m unittest discover -s donations -p 'test_*.py'
.venv/bin/python tools/package-payment.py
```

Результаты: `build/libs/VaultTracker-0.17.77-preview-folia26.jar` и `build/distributions/payment-service-0.17.77.zip` с `.sha256`. ZIP содержит исходники, шаблон конфигурации и скрипты; Python runtime в него не входит. Для старого Paper 1.21.11 существует отдельный вариант `-Plegacy=true` с JDK 21; это другая сборка, не вариант для Folia 26.

Web-проверки: Node.js 20+, затем `npm install`, `npx playwright install chromium`, `npm run test:web`. Если нужен уже установленный Chrome, задайте `PLAYWRIGHT_CHANNEL=chrome`. Эти тесты не обращаются к настоящему Telegram, Minecraft или базе. Скриншоты пишутся в игнорируемый `work/`.

## Возможности и навигация

- Регистрация сундуков табличкой `[v]`/`[vault]` либо рамкой с бумагой; учёт UUID, двойных сундуков и изменений содержимого.
- Русские/английские названия предметов, алиасы АР/ИР, поиск, рейтинги, ресурсы друзей и компас к своему хранилищу.
- Telegram: поиск, кабинет, ресурсы, статистика, настройки, друзья и личные сообщения `/tg`.
- Поддержка: жалобы, предложения, багрепорты, заявки на разбан и вложения. Автор жалобы на игрока получает уведомления о взятии, завершении и повторном открытии.
- Root в личном кабинете: команда и роли, аналитика, экономика, техническое управление. «Мой персонаж» тоже только Root. Super/Admin сохраняют собственные границы доступа; скрытие кнопок не заменяет проверку в handler.
- Новостной топик Telegram → объявление со ссылкой в игре; `/nr` повторяет последнюю новость. `/offtop` и `/unofftop` управляют ограничением только нужного Telegram-топика.
- Отдельный платёжный процесс: проверка заказа FunPay, кошелёк в целых сотых монеты, Premium/Premium Lite, одноразовая награда за привязку, VotifierPlus и три сайта голосования.
- Голоса: минимум 24 часа между начислениями одной площадки на UUID, durable retry, уведомления, месячный ТОП-3 и правила ничьих.
- CoreProtect Mini App: SELECT-only поиск с фильтрами, русскими материалами, offline-никами и копированием команды отката. Выполнения отката из приложения нет.
- Telegram-статистика: метаданные сообщений выбранных чатов, включая сообщения самого VaultTracker и игровой мост. Аналитика использования бота — отдельная база и отдельный интерфейс.

## Основные команды

| Команда | Назначение |
| --- | --- |
| `/topitem DIAMOND`, `/itemtop АР` | Топ ресурсов |
| `/topitem Ник`, `/topitem Ник ИР` | Ресурсы игрока |
| `/find` | Интерактивный поиск собственных ресурсов |
| `/tg Ник текст` | Личное сообщение связанному игроку |
| `/vtrack mine` | Свои зарегистрированные хранилища |
| `/vtrack link код` | Привязка своего UUID к Telegram |
| `/unlink` | Отвязка; только игрок с `isOp() == true` |
| `/vtrack status` | Состояние хранилищ/подключения |
| `/vtrack rescan` | Сверка уже зарегистрированных мест в загруженных чанках |
| `/vtrack reload` | Перечитать настройки и перезапустить Telegram-компоненты |
| `/nr` | Повторить новость в игре |

Полный декларативный список и permissions: [plugin.yml](src/main/resources/plugin.yml). `/nr` имеет отдельное право `vaulttracker.news.repeat`; Root Telegram и Minecraft OP — разные системы прав.

## Настройка и эксплуатация

YAML-шаблоны находятся в `src/main/resources/`; плагин создаёт отсутствующие файлы в `plugins/VaultTracker`. Существующие значения не нужно заменять шаблоном. Основные разделы: [платёжный сервис](donations/README.md), [CoreProtect](docs/coreprotect-viewer.md), [статистика Telegram](docs/telegram-analytics.md), [аналитика бота](docs/bot-analytics.md).

Сначала создайте отдельный стенд без production-токенов. Основной сервер с игроками не останавливать и не перезагружать ради разработки. Замена JAR — в согласованное окно со штатным рестартом; PlugMan/hot reload не является поддерживаемым способом обновления. При переносе сохраните прежний `server-id`, файлы данных, HMAC keys, offsets, роли и очереди. Подробная последовательность — в [инструкции передачи](docs/handoff.md).
